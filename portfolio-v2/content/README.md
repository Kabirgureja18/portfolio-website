# Portfolio content

`portfolio.json` is the editable source for the final React site. Empty strings and empty lists are intentional: they mean Kabir has not supplied the evidence or copy yet.

Add real assets to the future `public/images`, `public/artwork`, `public/photography`, and `public/certificates` folders, then reference them from the matching list in `portfolio.json`.

Never replace empty values with invented achievements, statistics, names, projects, or social links.
